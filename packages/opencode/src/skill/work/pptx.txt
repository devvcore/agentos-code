# Slide decks (.pptx)

A good deck makes one point per slide, the slide title states that point, and the evidence is real (native charts and tables, not decoration). If the user supplies a template or an existing deck, its layouts, fonts, and colors are the design system. Use them and don't invent your own.

Nothing is bundled with this skill. Write the snippets below into a scratch directory (for example `.work/`), run them with `python3`, and clean up afterwards.

## Setup and availability

```bash
python3 -c "import pptx; print('python-pptx', pptx.__version__)" || python3 -m pip install --quiet python-pptx
command -v soffice || ls /Applications/LibreOffice.app/Contents/MacOS/soffice 2>/dev/null   # optional: PPTX -> PDF
command -v pdftoppm || python3 -c "import fitz" 2>/dev/null && echo "renderer ok"         # optional: PDF -> PNG
command -v markitdown                                                                       # optional reader
```

If a tool is missing, use the next option down, and tell the user which checks you could not run.

## Choose the approach

| Task | Approach |
|---|---|
| Read or summarize a deck | `markitdown deck.pptx` if available, else the inspect script below (slide text plus notes) |
| New deck, no template | Outline first, then python-pptx with the default layouts, set to 16:9 |
| New deck on the user's template | `Presentation("template.pptx")`, inspect the layouts, delete the sample slides, and add slides from the template's layouts |
| Edit an existing deck | Structural changes first (add, delete, reorder, duplicate), then content edits in the placeholders that already exist |
| Charts | Native python-pptx charts (editable in PowerPoint), not matplotlib PNGs |
| Data tables | `shapes.add_table`, 6 rows or fewer where you can; move the full data to an appendix or a spreadsheet |
| Speaker notes | `slide.notes_slide.notes_text_frame.text = ...` |

## Plan the deck before you write code

Write the outline as a list of **action titles**, one sentence per slide that states the conclusion ("EMEA drove 70% of Q3 growth", not "EMEA Results"). Someone who reads only the titles should get the whole story. For each slide, note the single piece of evidence (a chart, table, number, or image) that proves the title. Typical shape: title, then an executive summary (3 bullets), then 1 slide per key point, then next steps or the ask, then an appendix. If the user gave you content, keep their facts and numbers exactly as given.

## Inspect a template or an existing deck

```python
# .work/inspect_pptx.py <deck.pptx>
import sys
from pptx import Presentation
from pptx.util import Emu
prs = Presentation(sys.argv[1])
print(f"size: {Emu(prs.slide_width).inches:.2f} x {Emu(prs.slide_height).inches:.2f} in")
for m_i, master in enumerate(prs.slide_masters):
    for l_i, layout in enumerate(master.slide_layouts):
        phs = [(ph.placeholder_format.idx, str(ph.placeholder_format.type).split(".")[-1], ph.name) for ph in layout.placeholders]
        print(f"layout[{m_i}.{l_i}] {layout.name!r}: {phs}")
for s_i, slide in enumerate(prs.slides):
    print(f"--- slide {s_i + 1} layout={slide.slide_layout.name!r}")
    for sh in slide.shapes:
        ph = f" ph#{sh.placeholder_format.idx}" if sh.is_placeholder else ""
        text = sh.text_frame.text.replace("\n", " / ")[:100] if sh.has_text_frame else ""
        print(f"   {sh.shape_type}{ph} {sh.name!r} {text}")
    if slide.has_notes_slide and slide.notes_slide.notes_text_frame.text.strip():
        print("   notes:", slide.notes_slide.notes_text_frame.text[:100])
```

Match placeholders by their `idx`, not by their position in the shape list. A layout's title is usually idx 0 and its body is usually idx 1, but templates differ, so check.

## Building with python-pptx

```python
from pptx import Presentation
from pptx.util import Inches, Pt
from pptx.chart.data import CategoryChartData
from pptx.enum.chart import XL_CHART_TYPE, XL_LEGEND_POSITION

prs = Presentation()                                  # or Presentation("template.pptx")
prs.slide_width, prs.slide_height = Inches(13.333), Inches(7.5)   # 16:9. Skip this when using a template
TITLE, CONTENT, TITLE_ONLY = prs.slide_layouts[0], prs.slide_layouts[1], prs.slide_layouts[5]

s = prs.slides.add_slide(TITLE)
s.shapes.title.text = "Q3 Business Review"
s.placeholders[1].text = "Finance team, October 2026"

s = prs.slides.add_slide(CONTENT)
s.shapes.title.text = "Growth came from EMEA while costs held flat"
body = s.placeholders[1].text_frame
body.text = "EMEA revenue +38% year over year"
for text, level in [("Two new enterprise logos", 1), ("Opex flat at $4.1M", 0), ("Gross margin 71% (+2 pts)", 0)]:
    p = body.add_paragraph(); p.text = text; p.level = level
s.notes_slide.notes_text_frame.text = "Lead with EMEA. The logo wins are in the appendix if asked."

s = prs.slides.add_slide(TITLE_ONLY)
s.shapes.title.text = "EMEA drove 70% of Q3 growth"
data = CategoryChartData()
data.categories = ["Q1", "Q2", "Q3"]
data.add_series("EMEA", (1.1, 1.3, 1.8))
data.add_series("Americas", (2.0, 2.1, 2.2))
chart = s.shapes.add_chart(XL_CHART_TYPE.COLUMN_CLUSTERED, Inches(0.8), Inches(1.6), Inches(11.7), Inches(5.3), data).chart
chart.has_legend = True; chart.legend.position = XL_LEGEND_POSITION.BOTTOM; chart.legend.include_in_layout = False
chart.value_axis.has_major_gridlines = False
chart.value_axis.tick_labels.number_format = '"$"0.0"M"'; chart.value_axis.tick_labels.number_format_is_linked = False
plot = chart.plots[0]; plot.has_data_labels = True
plot.data_labels.number_format = '"$"0.0"M"'; plot.data_labels.number_format_is_linked = False
plot.data_labels.font.size = Pt(12)

prs.save("deck.pptx")
```

Default layout indexes: 0 title, 1 title and content, 5 title only, 6 blank. They differ in templates, so choose layouts by `layout.name` after you inspect them.

## Structural edits on existing decks (do these before content edits)

```python
import copy
from pptx import Presentation

def delete_slide(prs, index):
    sld_id = prs.slides._sldIdLst[index]
    prs.part.drop_rel(sld_id.rId)
    prs.slides._sldIdLst.remove(sld_id)

def move_slide(prs, old, new):
    lst = prs.slides._sldIdLst
    el = lst[old]; lst.remove(el); lst.insert(new, el)

def duplicate_slide(prs, index):
    """Appends a copy at the end. Charts in the copy share the original's chart part, so rebuild charts whose data differs."""
    src = prs.slides[index]
    dst = prs.slides.add_slide(src.slide_layout)
    for sh in list(dst.shapes):
        sh._element.getparent().remove(sh._element)
    rid_map = {}
    for rid, rel in src.part.rels.items():
        if rel.reltype.endswith(("/slideLayout", "/notesSlide")):
            continue
        rid_map[rid] = (dst.part.rels.get_or_add_ext_rel(rel.reltype, rel.target_ref) if rel.is_external
                        else dst.part.rels.get_or_add(rel.reltype, rel.target_part))
    for sh in src.shapes:
        el = copy.deepcopy(sh._element)
        for node in el.iter():
            for attr in list(node.attrib):
                if attr.startswith("{http://schemas.openxmlformats.org/officeDocument/2006/relationships}") and node.get(attr) in rid_map:
                    node.set(attr, rid_map[node.get(attr)])
        ext = dst.shapes._spTree.find("{http://schemas.openxmlformats.org/presentationml/2006/main}extLst")
        ext.addprevious(el) if ext is not None else dst.shapes._spTree.append(el)   # shapes must precede extLst
    return dst

prs = Presentation("existing.pptx")
# Example: drop the template's sample slides and keep slide 1 as the cover
for i in reversed(range(1, len(prs.slides))):
    delete_slide(prs, i)
```

Once the structure is right, fill the placeholders that already exist on each slide (`slide.placeholders[idx]`). Don't draw new text boxes on top of them. Remove the placeholders you leave unused, because empty ones show "Click to add text" in edit view:

```python
for ph in list(slide.placeholders):
    if ph.has_text_frame and not ph.text_frame.text.strip():
        ph._element.getparent().remove(ph._element)
```

## Text budgets (keep text inside its box)

- Title: 60 characters or fewer, one line, two at most. Body: 6 bullets or fewer, each 12 words or fewer. Everything else goes in the speaker notes.
- As a rough guide at 18 pt on a 16:9 slide, a full-width body box holds about 90 characters per line and 12 lines. At 24 pt it holds about 65 characters per line and 9 lines.
- If content doesn't fit, split the slide. Don't shrink the font below 14 pt for body text or 10 pt for footnotes and sources.
- `text_frame.word_wrap = True` on text boxes you create. Don't rely on auto-fit. python-pptx does not compute it, and LibreOffice renders it differently.

## Design guidance

- One idea per slide, with generous whitespace and a consistent left alignment edge. Use the same title position on every slide (let the layout handle it).
- Show the data: a native chart with the takeaway in the title, direct data labels instead of gridlines, and one highlighted series in an accent color with the rest in gray.
- Use the template's theme fonts and colors. With no template, use 1 sans-serif font, 1 dark text color, 1 accent color, and a white or very light background.
- Put the source line for data at the bottom in 10-11 pt.
- Avoid things that look generic or machine-made: decorative bars or lines under titles, gradients, drop shadows, emoji bullets, clip-art icons for their own sake, beige or cream palettes, stock "abstract tech" imagery, walls of bullets, and every slide using the same bullet layout. Vary the layouts to fit the content (chart, big number, two-column comparison, table).
- Images: use only what the user supplied or clearly asked for, and keep the aspect ratio (set only width or only height).

## Common pitfalls

- Titles that name a topic ("Revenue") instead of stating a point ("Revenue up 12% on pricing").
- Text overflowing its placeholder. python-pptx won't warn you, so only the render will show it.
- Leaving the template's sample slides or empty placeholders in the deck.
- Mixing the 4:3 template size with 16:9 coordinates. Read `prs.slide_width` and `prs.slide_height` and position shapes relative to them.
- Charts pasted as images (not editable) and charts with a default legend and title that repeat the slide title.
- Hardcoded fonts that fight the template's theme.
- Overwriting the user's deck. Save to a new name unless told otherwise.

## VERIFY (mandatory before you say you're done)

### 1. Text and structure check

```python
# .work/check_pptx.py <deck.pptx>
import sys, re, json
from pptx import Presentation
from pptx.util import Emu
prs = Presentation(sys.argv[1])
PLACEHOLDER = re.compile(r"Click to (add|edit)|\{\{.*?\}\}|[Ll]orem ipsum|\bTODO\b|\bTBD\b|\bXXX+\b|\[insert", re.I)
report = {"slides": len(prs.slides), "placeholders_left": [], "empty_placeholders": [], "overflow_risk": [], "off_slide": [], "missing_titles": []}
for n, slide in enumerate(prs.slides, 1):
    if slide.shapes.title is None or not slide.shapes.title.text.strip():
        report["missing_titles"].append(n)
    for sh in slide.shapes:
        if sh.left is not None and (sh.left < 0 or sh.top < 0 or sh.left + sh.width > prs.slide_width or sh.top + sh.height > prs.slide_height):
            report["off_slide"].append({"slide": n, "shape": sh.name})
        if not sh.has_text_frame:
            continue
        text = sh.text_frame.text
        if PLACEHOLDER.search(text):
            report["placeholders_left"].append({"slide": n, "shape": sh.name, "text": text[:80]})
        if sh.is_placeholder and not text.strip():
            report["empty_placeholders"].append({"slide": n, "shape": sh.name})
        if not text.strip() or sh.width is None:
            continue
        # Rough fit estimate: average glyph width is about 0.5 em; line height is about 1.2 em
        size = max([r.font.size.pt for p in sh.text_frame.paragraphs for r in p.runs if r.font.size] or [18])
        per_line = max(1, int(Emu(sh.width).pt * 0.9 / (size * 0.5)))
        lines = sum(max(1, -(-len(p.text) // per_line)) for p in sh.text_frame.paragraphs)
        if lines * size * 1.2 > Emu(sh.height).pt * 1.05:
            report["overflow_risk"].append({"slide": n, "shape": sh.name, "est_lines": lines, "font_pt": size})
print(json.dumps(report, indent=2))
```

`placeholders_left`, `empty_placeholders`, and `off_slide` must be empty. Every entry in `overflow_risk` must be looked at in the render. The estimate is rough, and it assumes 18 pt when the size comes from the theme.

### 2. Render every slide and look at it


Open every slide image and check for text overflow or clipping, overlapping shapes, readable chart labels, consistent title positions, and no leftover template content. Fix what you find and render again. LibreOffice's rendering is close to PowerPoint's but not identical (fonts may substitute).
